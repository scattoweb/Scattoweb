# Scattoweb

Сайт-визитка Scatto Team (сайты, автоматизация, брендинг для небольшого бизнеса). Цель сайта — заявки, трафик в основном из Instagram (мобильный).

Перед любой работой над дизайном, текстами или вёрсткой читай `docs/brief.md` — там референсы и установки, по которым принимаются решения. Коротко:

- Одно главное действие — написать нам (Telegram / WhatsApp / форма на 3 поля); до него ≤ 1 тапа с любого экрана.
- Первый экран: что делаем → для кого → результат.
- Кейсы по схеме «задача → решение → результат → отзыв → CTA»; цены «от X ₽» видны.
- Mobile first (375px), LCP ≤ 2.5 с, CLS ≤ 0.1, INP ≤ 200 мс.
- Анимация только с назначением: без скролл-джекинга и долгих прелоадеров, только `transform`/`opacity`, поддержка `prefers-reduced-motion`.
- Без стоковых фото людей и пустых фраз про «команду профессионалов».

## Стек и запуск

Статический сайт без сборки: `index.html`, `assets/css/style.css`, `assets/js/main.js`, шрифт Onest (self-hosted, `assets/fonts`). Локально: `python3 -m http.server` в корне репозитория.

Тексты всех блоков главной — `docs/copy.md` (места для подстановки помечены `[...]`).
